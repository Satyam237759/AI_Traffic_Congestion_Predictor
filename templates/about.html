What is AI Traffic Congestion Predictor?

AI Traffic Congestion Predictor is a student machine-learning project that estimates traffic congestion using details such as time, day, estimated vehicle count, weather and road type.

How does it work?

  1. The user enters road condition details.
  2. The Flask application sends the values to a trained Random Forest model.
  3. The model predicts Low, Medium or High congestion.
  4. The result and model confidence are displayed on the page.

Technology used

Python, Flask, Pandas, Scikit-learn, HTML, CSS and JavaScript.

Important: This project uses synthetic sample data for demonstration. It does not connect to traffic cameras, GPS services or live traffic APIs. Its predictions are educational estimates, not reliable real-world forecasts.
